# Fleet landing-page design ranking

> **WITHDRAWN — do not use for design decisions.** The ranking was produced before independently validating each landing page against the current product contract. The purpose audit found 9 material mismatches, 7 partial/stale explanations, and 2 products with no page. Aesthetic ordering is invalid until those purpose failures are corrected or explicitly scored as failures.

The visual scores below are retained only as secondary craft diagnostics. The canonical review now requires an independent purpose score of at least 85/100; purpose and visual scores are not averaged, and visual quality cannot rescue a purpose failure.

Generated: 2026-08-27  
Scope: all 55 current Fleet product records. The shared `ios-landings` factory is infrastructure and is the only catalog record excluded. The set contains 46 public pages, seven local visual surfaces, and two products with no implemented visual page.

This supersedes the earlier 40-entry ranking, which incorrectly applied active/public lifecycle exclusions to a request for every landing page.

## Method

Scores judge the page, not the product. The review weighs product-purpose clarity, visual direction and distinctiveness, first-viewport composition, tangible proof, content hierarchy, and responsive behavior at 390, 768, and 1440px. A default application surface counts when no separate marketing page exists. Products with no visual surface remain in the ranking with a score of zero so the inventory still reconciles.

Evidence: [original 40-page scan](../artifacts/design/landing-ranking-2026-08-27/scan.json), [six recovered public pages](../artifacts/design/landing-ranking-2026-08-27/scan-missing-public.json), [seven local surfaces](../artifacts/design/landing-ranking-2026-08-27/scan-local.json), [recovered public desktop](../artifacts/design/landing-ranking-2026-08-27/contact-missing-1440.jpg), [recovered public mobile](../artifacts/design/landing-ranking-2026-08-27/contact-missing-390.jpg), [local desktop](../artifacts/design/landing-ranking-2026-08-27/contact-local-1440.jpg), and [local mobile](../artifacts/design/landing-ranking-2026-08-27/contact-local-390.jpg).

## Verdict bands

- **90–100 — benchmark quality:** Office OS, Protein Index, Local AI Video Studio, CodeVetter, TrueHire, RolePatch, and PostTrainLLM.
- **85–89 — strong:** AliveVille through SaaS Maker in the ordered table.
- **80–84 — good foundation:** Look Sideways through Calorie.
- **70–79 — usable but needs a sharper product-specific direction:** Memory Map through App Health.
- **Below 70 — redesign, repair, or a real landing mode required:** India Standards through Companion Robot.
