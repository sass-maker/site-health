## ADDED Requirements

### Requirement: Fleet routes specialized design-engineering work through focused skills
Fleet SHALL use focused design-engineering skills for reference research,
component pattern mining, web 3D delivery, and creative browser effects while
retaining the existing preserve/overhaul, evidence, quality, and owner gates.

#### Scenario: Specialized work occurs inside a meaningful visual change
- **WHEN** a meaningful visual change needs one of the specialized workflows
- **THEN** the focused skill supplies task evidence and implementation guidance while `design-workflow` remains the completion authority

#### Scenario: A focused workflow is used for planning only
- **WHEN** the user asks only for research, comparison, or technical shaping
- **THEN** the focused skill may complete without creating a design-review receipt or claiming that a visual implementation shipped
