## ADDED Requirements

### Requirement: SaaS Maker may consume a public token-impact projection

SaaS Maker SHALL remain a static public directory and MAY embed one public,
aggregate-only daily token-impact projection generated by Fleet. The projection
MUST contain only the measures and bounded pulse buckets defined by the
public-token-impact capability. SaaS Maker MUST NOT own an ingest runtime,
credentials, database, raw events, private telemetry queries, or operational
controls.

#### Scenario: Visitor opens the token-impact chapter
- **WHEN** the static SaaS Maker page loads
- **THEN** it renders the build-time public aggregate projection without authentication or access to private Fleet state

#### Scenario: No valid snapshot is available at build time
- **WHEN** Fleet has not generated a valid public projection
- **THEN** the rest of the static directory remains buildable and the chapter renders its truthful awaiting-data state

#### Scenario: Private telemetry exists upstream
- **WHEN** Fleet infrastructure holds ingest credentials, deduplication state, or non-public operational data
- **THEN** none of that state is embedded in the SaaS Maker build or returned by the public projection
