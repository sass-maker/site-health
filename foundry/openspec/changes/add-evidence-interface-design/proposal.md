## Why

Fleet's design-engineering toolkit covers inspiration, component patterns, web
3D, and creative effects, but it has no focused contract for evidence-heavy
interfaces. Agents still improvise how reports, benchmarks, comparisons,
dashboards, calculators, and decision pages protect factual meaning while
making the central conclusion easy to understand.

## What Changes

- Add an `evidence-interface-design` child skill for decision framing, claim
  provenance, dual-speed reading, honest visual encoding, and calculator state.
- Route evidence-heavy interface work through the existing
  `design-engineering` parent while keeping `design-workflow` and Impeccable
  authoritative for visual direction and completion.
- Add a progressively loaded evidence contract, generated skill metadata, an
  execution profile, focused tests, and Fleet skill-inventory documentation.
- Adapt reusable evidence-design principles in Fleet-native language without
  importing Vercel branding, assets, CSS, tokens, or fixed stylistic rules.

## Capabilities

### New Capabilities

- `evidence-interface-design`: Defines how Fleet agents shape and validate
  evidence-heavy reports, benchmarks, comparisons, dashboards, calculators,
  and decision pages.

### Modified Capabilities

None.

## Impact

- Adds one canonical child skill under `foundry/ops/skills/` and extends the
  existing parent router, capability metadata, documentation, and focused tests.
- Adds no production dependency, credential access, production configuration,
  deployment, migration, or release behavior.
